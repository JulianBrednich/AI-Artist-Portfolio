No Notes Studio · 3D-to-AI image workflow

3D Layout → AI Image

  • Blender
  • Nano Banana
  • Photoshop
  • Set Design
  • Camera & Composition
  • Continuity

Rather than leaving composition and spatial relationships to chance, I build the location in 3D first. A simple dummy character establishes the exact pose and placement, while the virtual camera locks the viewpoint, lens framing and perspective. The resulting 3D render becomes the structural reference for AI image generation with Nano Banana, followed by targeted refinement in Photoshop.

This approach provides direct artistic control over perspective, camera angle, character pose, object placement and set design. Because each shot is grounded in the same 3D environment, spatial relationships remain consistent across the sequence: objects stay where they belong, and the set does not unexpectedly change between shots.

3D Render vs. AI Image

Each pair compares the 3D camera and layout reference with the AI-assisted final image.

How it works

  1. Build the location in Blender: define the architecture, props, layout and spatial relationships.
  2. Block the character: position a dummy placeholder to define the pose and placement in the scene.
  3. Lock the camera: establish perspective, composition and shot framing in 3D.
  4. Generate with Nano Banana: use the 3D render as a visual reference for the intended final look.
  5. Refine in Photoshop: polish details and bring the image to its final finish.
  6. Maintain continuity: reuse the same 3D set across shots to preserve camera logic, object positions and set design.

No Notes Studio · Reference workflow for AI video

Single-Camera Facial Capture → 3D Reference → AI Video

  • ComfyUI
  • MediaPipe
  • Python
  • Blender
  • MetaHuman
  • ARKit
  • Seedance

A facial motion capture workflow that only needs a single camera. Developed at No Notes Studio to give AI video generation precise control over performance and timing: an actor’s face is tracked from ordinary video, transferred to a MetaHuman head in Blender, and rendered as a reference for Seedance.

How it works

  1. Track in ComfyUI: custom comfyui-facelines nodes use MediaPipe to capture 3D facial landmarks, ARKit-style blendshapes and head pose; smooth and conform footage to 24 fps.
  2. Generate references: create face-line reference frames and a time-coded emotion script for the prompt.
  3. Export JSON: save landmarks, blendshapes and head transforms.
  4. Animate in Blender: a custom Python script keys the MetaHuman shape keys and head transforms.
  5. Render 3D reference: place the animated head in the blocked-out set.
  6. Generate with Seedance: use the render to guide facial performance, framing and timing.
  7. Change details in the prompt: adjust individual props, such as the coffee cup and microphone, while keeping the 3D reference as the foundation.
